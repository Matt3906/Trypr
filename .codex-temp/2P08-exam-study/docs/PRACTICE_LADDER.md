## Best way to use the ladder

1. Attempt the starter file without opening the answer key.
2. Run only that level's test file.
3. Fix failures one at a time.
4. Write down the mistakes you made.
5. Re-do the same level later from a clean copy if it felt shaky.

## Rule for Friday

If you can complete Level 4 calmly and explain your fixes, you are much closer to being exam-ready than if you only read notes.
