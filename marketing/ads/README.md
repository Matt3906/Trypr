# Trypr ads: what to post, and when

Everything here is sized for Instagram: feed posts are 1080×1350 (4:5), stories are 1080×1920. Portfolio images are 3840×2160 and are not for Instagram.

## How the folders work

| Folder | How to post it |
|---|---|
| `carousel-1-western-uplands/` | **One post, all 5 images**, in file order (1 → 5). |
| `carousel-2-canoe-trip/` | **One post, all 5 images**, in file order. |
| `carousel-3-how-it-works/` | **One post, all 5 images**, in file order. |
| `carousel-4-why-i-built-trypr/` | **One post, all 5 images**, in file order. |
| `carousel-5-every-kind-of-trip/` | **One post, all 5 images**, in file order. |
| `carousel-6-transit-step-by-step/` | **One post, all 5 images**, in file order. |
| `carousel-7-ai-travel-agent/` | **One post, all 5 images**, in file order. |
| `posts/` | **One image per post.** Each one stands alone. |
| `stories/` | **Stories**, one image each. Best posted the same day as the feed post they match (see the plan). |
| `portfolio/` | Your portfolio site, not Instagram. |
| `source/` | The generator that made all of this. Not for posting. |

To post a carousel on Instagram: tap **+** → **Post** → **Select multiple** → pick the slides in order (1, 2, 3, 4, 5).

## Don't post these in the same week

Some posts tell the same story in a different format. Space them out:

- `posts/02-western-uplands` and `carousel-1-western-uplands` (same hike)
- `posts/08-portage`, `carousel-2-canoe-trip` and `stories/story-07-new-canoe` (same canoe route)
- `posts/03-together` and `posts/12-collage` (both "all in one place")
- Founder feed posts: `posts/04-founder`, `posts/20-founder-quote` and `carousel-4-why-i-built-trypr`. Keep them at least two weeks apart. (`stories/story-08-hi` is meant to go out with the founder carousel.)
- `posts/12-collage` and `carousel-5-every-kind-of-trip` (both "every kind of trip")
- `posts/23-long-way` and `carousel-5-every-kind-of-trip` (same car photo)
- Munich → Salzburg journey: `carousel-6-transit-step-by-step`, `posts/27-transit-plan-the-train` and `stories/story-11-transit` all show it. Post the carousel first; the story can go out the same day.
- AI agent: `carousel-7-ai-travel-agent`, `posts/38-ai-travel-agent` and `stories/story-12-ask-trypr` overlap. Keep the carousel and `38` at least a week apart.

## Week 0: the teaser

Post `posts/00-teaser-new-beginning` on its own, 3 to 7 days before week 1. It announces the new look and nothing else, so don't post anything else that week. Pin it to the top of the profile until week 1 starts.

## What's real and what's an example

- **Real:** every hiking and canoe route, distance, portage and campsite. They come from OpenStreetMap and Trypr's own routing. The map views in `carousel-3-how-it-works` are real screenshots of the app; its search box and "Add campsite" dialog are redrawn to match the app.
- **Examples:** the packing list (`06`), the budget amounts (`07`) and the road-trip distances (`14`, marked "~").
- **Transit examples:** every transit image is labelled "Example journey". The Munich → Salzburg line names, stops and times are illustrative, not a live timetable. The hints (change times, subway and ticket tips, station sign words) are what the app actually shows.
- **Don't promise platform numbers, live delays or "your stop is next" alerts in captions yet.** The app only shows those in development builds until a licensed data source is added. None of these ads show them.
- **AI examples:** the suggestions in the AI ads (trattoria, boutique hotel, prices, ratings) are labelled "Example suggestions". Real suggestions depend on the trip.
- **Check before posting:** `posts/05-spreadsheets` and `stories/story-05-spreadsheets` show a person in the car, and the story shows the front licence plate.

Map images need the credit "Map data © OpenStreetMap contributors". It's already on every map image; keep it if you crop.
